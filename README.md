# 江苏中职2026学测刷题工具
本地静态网页刷题软件，用于**江苏中专2026中职学业水平测试（学测）**练习备考，支持多题库、练习/考试双模式。

> 

> 📌声明：本工具为个人自制学习练习软件，**非官方考试系统，题目仅供练习参考，不代表官方真题**。
>
> 📱版本说明：当前仅完成**安卓APK版本**；苹果、其他平台版本正在制作中，后续会陆续发布。

## ✨已实现功能
- 📚多题库选择
- 📝两种答题模式：
  - 练习模式：可随时查看答案解析
  - 考试模式：答题期间隐藏答案，交卷之后统一查看解析
- 🖼️支持电工电子等专业带图题目
- ⏱️考试倒计时，时间结束自动交卷
- 📊考完展示得分、正确率，错题一键跳转复盘
- ⭐题目收藏标记功能
